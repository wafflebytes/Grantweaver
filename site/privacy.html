Privacy Policy

v0.1 · July 2026

What we collect

(1) The organization profile you type into setup (name, mission, focus areas, state, team size). (2) Grant pipeline records you create (public Grants.gov opportunity metadata plus stage). (3) Evidence pointers: Slack permalinks, channel IDs, message timestamps, and a tag. Never message text, files, or attachments. (4) Feedback ratings on Grantweaver's responses. (5) Agent state and logs: goals, tool names, run status, token counts if available, and sanitized errors, with no Slack message content.

What we never collect or store

Slack message content, file content, or user DMs. When Grantweaver reads workspace content it does so live via Slack's Real-Time Search API, uses it only to answer the current request, and discards it. We do not train AI models on your data, ever.

AI processing

Requests are processed through an OpenAI-compatible large-language-model API; the current agent model is MiniMax 2.7. Content transits the provider only for the duration of your request and is never stored by Grantweaver. Provider-side handling follows that provider's API terms. We never train models on your data ourselves. AI outputs may contain errors, so always review drafts before submission.

Controls

Use /grantweaver settings to exclude channels from AI search and proactive scans. Use /grantweaver logs to inspect recent runs and /grantweaver state to inspect the privacy-safe state for a conversation. Use /grantweaver reset or email us to delete workspace data.

Retention & deletion

Profile, pipeline, and pointer data persist until you delete them or uninstall the app; uninstalling schedules deletion within 30 days. Email chaitanyajha.quantum@gmail.com to access, export, or delete your data.

Contact & incidents

Privacy and security contact: chaitanyajha.quantum@gmail.com. We notify affected workspaces of confirmed incidents without undue delay.
